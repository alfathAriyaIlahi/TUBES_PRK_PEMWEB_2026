# Ruang Hukum: Konsultasi Hukum Online (Kelompok 25)

Tugas Besar Pemrograman Web 2026. PHP native, MySQL, Bootstrap 5. Metode: Waterfall.

## Menjalankan di laptop
1. Nyalakan Apache dan MySQL (XAMPP atau Laragon).
2. Buka http://localhost/phpmyadmin, klik tab **SQL**, tempel seluruh isi `database/schema.sql`, klik **Go**.
3. Buka http://localhost/TUBES_PRK_PEMWEB_2026/kelompok/kelompok_25/
